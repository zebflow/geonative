# geonative

A lightweight, pure-Rust geospatial library — meta-crate.

Zero default features. Opt in to formats, processing, and conversion via Cargo features.

```toml
geonative = { version = "0.0.1", features = ["file-gdb", "file-geoparquet", "convert"] }
```
