# geonative-tile

Slippy-map tile coordinate math for the [geonative](https://geonative.zebflow.com) geospatial library.

Web Mercator (EPSG:3857) XYZ ↔ lng/lat conversion, tile bounding-box computation, pixel projection within a tile, and metatile grouping. Foundation for MVT vector tiles, WMS/WMTS raster tiles, and any other slippy-map-style serving.

Pure-Rust, no heavy deps.
